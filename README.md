نظام تجاري متطور ومتكامل مصمم خصيصاً لإدارة عمليات البيع بالجملة والتجزئة، إدارة المخازن، حسابات العملاء، والفواتير السريعة.

---

### ✨ المميزات الرئيسية (Key Features)
1. **نظام فواتير مبيعات فوري:** دعم الباركود، حساب الإجمالي والخصم والضريبة، والطباعة الفورية للفواتير الحرارية والرسمية.
2. **إدارة الأصناف والمستودعات:** متابعة كميات المخزون، تنبيهات قرب نفاد الأصناف، وإدارة أسعار الجملة والتجزئة.
3. **سجل العملاء والديون:** متابعة مديونيات العملاء ودفعات السداد مع تقارير كشف حساب تفصيلية.
4. **لوحة تحكم إحصائية:** مؤشرات يومية للمبيعات، الأرباح، وأكثر المنتجات مبيعاً.
5. **واجهة استخدام عربية متجاوبة وسريعة:** تدعم الشاشات اللمسية وتعمل على مختلف الأجهزة.

---

### 🛠️ البنية التقنية (Tech Stack)
- **Frontend:** Modern Vanilla JavaScript, CSS3 Grid/Flexbox, HTML5
- **Printing Engine:** Thermal Receipt & PDF Print Drivers

---

### 🚀 طريقة التشغيل (How to Run)
فتح ملف `index.html` في أي متصفح ويب حديث.
